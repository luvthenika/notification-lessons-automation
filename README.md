# Academic Schedule Notifier (C#) 📚

A specialized C# application that automates university schedule tracking and sends real-time lesson alerts via the **Telegram Bot API**.

## 🌟 Why I built this
Managing a complex university timetable can be tricky. I developed this tool to proactively notify me about upcoming lectures, ensuring I never miss a link or a room number.

## 🛠 Features
- **Dynamic Scheduling:** Checks current time against a predefined academic timetable.
- **Telegram Integration:** Leverages the `Telegram.Bot` library to push instant notifications.
- **Custom Alert Logic:** Includes specific triggers for different days of the week and lecture types.

## 💻 Tech Stack
- **Language:** C#
- **Platform:** .NET
- **API:** Telegram Bot API
- **Libraries:** Telegram.Bot
